# Track 02 힙합 충남송 가사 초안 - 「쌓는 중」 (가제)

> **AI 제안 아이디어 참고안입니다.** 제출곡의 작사는 응모자(사람)가 합니다. 응모자가 고르고 크게 고쳐 쓰기 위한 재료이며, 이 가사를 제출 가사에 그대로 쓰지 않습니다. 사용 내역은 `docs/ai-usage-log.md`와 신청서에 사실대로 기록합니다.

## 소재 선택
신두리 해안사구(태안). 이유: Track 01(간월암, 바다·물때·서정)과 겹치지 않는 '바람이 모래를 한 알씩 쌓는 느린 속도'를 2030의 "내 페이스" 메시지로 바꿀 수 있고, "충남은 가까운데 아직 다 못 본 곳"(brief 메시지 1)으로 확장된다.

## 사용한 사실 (materials.md 카드 2, 확인된 것만)
바람이 쌓은 모래언덕 / 천연기념물 / 사구 너머 갯벌과 바다 / 탐방로 / 쇠똥구리(복원 언급). 수치·해당화 등 개별 식물 종은 쓰지 않음.

## Suno 스타일 참고 (데모용)
```
Korean hip-hop, laid-back boom bap with light trap hi-hats, warm Rhodes and soft guitar loop, wind ambience at intro, 92 BPM, confident but relaxed male rap verses, melodic singalong hook with group shouts, clear Korean pronunciation, youthful and stylish, breezy mood, 3 minutes
```
Exclude: `trot, screaming, heavy distortion, English lyrics, explicit lyrics`

## 위험과 고쳐 쓸 때 볼 점
1. 식상함: "천천히 가도 괜찮아" 계열 위로 메시지는 흔하다(Track 01 '천천히 와도'와 결이 가까움). 응모자만의 구체 장면(실제 방문 경험)으로 바꿔 차별화할 것.
2. 유사 문구: "쌓는 중", "내 페이스" 류는 일반 표현이라 기존 곡·광고와 겹칠 수 있다. 후렴 확정 후 멜론·지니·유튜브 직접 검색(2차 유사성 조사) 필수. 충남 공식 슬로건·"어서와유" 미사용 확인.
3. 사실 오류 가능성: "쇠똥구리"는 카드상 '복원 언급'뿐이라 "제 몫을 굴리는 곳"은 현재 서식 단정으로 읽힐 수 있음. 사용 전 충남도 원문 재확인, 불확실하면 삭제. "천연기념물"은 카드에서 확인된 사실.
4. 톤: 힙합 어투가 관광 홍보 CM에서 가볍게 들리지 않도록 랩 라인은 응모자 말투로 다듬고, 라임은 직접 소리 내어 읽어 발음(받침 겹침)을 점검. 벌스 16마디는 brief 권고(8마디 이내)보다 길어 첫 30초 규칙은 인트로 훅으로 충족하며, 편곡 시 벌스 축약 검토.
5. 충남 근거 약점: 신두리는 태안 한정 소재라 "충남 전체" 공감은 벌스2 후반부("다 못 본 길")에 의존. '충남'이 훅 첫 줄 1회이므로 30초 내 반복 노출을 늘릴지 검토. 방언 '~유'는 사용하지 않음.
