## 1. 컨셉과 타깃
- 타깃: 2030. 숏폼(릴스·쇼츠) 배경음, 축제·행사 오프닝, 충남 홍보영상 속 빠른 컷 편집.
- 톤: 밝고 세련된 "이동하는 충남". 자랑·과시가 아니라 **발견과 기분**(공고 불채택 리스크 회피, brief 5절).
- 메시지 방향(후보 하나 선택은 사람): 발견형 "충남은 가까운데 아직 다 못 본 곳".
- 소재 제안: 신두리 해안사구(바람이 쌓은 결, 발자국, 사구 너머 바다, `materials.md` 2번)를 장면 축으로 하고, 충남 지명은 후렴에 1개 이상 넣는다. Track 01의 간월암과 겹치지 않게 차별화한다. 소재 최종 선택은 사람이 한다.
- '~유' 말투: 유사성 리포트상 충남도 '어서와유(U)' 캠페인과 겹침 위험이 높다. **훅에는 쓰지 않고**, 애드리브 1~2곳 이내로 제한하며 조롱·개그 톤은 금지한다.
- 수치·순위·"최고·최초" 단정은 쓰지 않는다. 신두리의 천연기념물 지정 등 사실은 사용 전 출처(`materials.md`) 재확인한다.

## 2. 트랙 사운드 설계
### 2-1. 권고 1개: 멜로딕 힙합(붐뱁 결의 단단한 드럼 + 노래하는 훅)
| 항목 | 값 |
|---|---|
| BPM | 탐색 범위 88~100, 권고 **96**(하프타임 느낌, 랩 벌스 여유) |
| 조성 | 마이너 또는 다이아토닉 장조 중 사람이 선택(권고: 밝은 톤을 위해 장조 기반 코드 4개 이내) |
| 편성 | 킥·스네어·하이햇, 서브 베이스, 어쿠스틱 피아노/일렉피아노 코드, 짧은 리드 1개 |
| 이유 | (1) 훅을 노래처럼 불러 15초 CM·숏폼 컷과 궁합이 좋고 후렴이 3회 이상 반복된다. (2) 트랩은 하이햇·808 밀도가 높아 홍보영상 삽입 시 소리가 작으면 묻힐 수 있다. (3) 저지클럽은 유행 장르 색이 강해 지자체 CM 톤과 거리가 있을 수 있다(가설). (4) 붐뱁 단독은 훅 각인이 약할 수 있다. (5) MC+DJ/트랙만으로 라이브 재현이 쉽다. |
| 샘플 | 외부 샘플 미사용 권장(직접 연주·자체 사운드) |

### 2-2. 훅 구조
- 훅 4줄 이내, 1줄 8~12음절, 핵심 구절 2회 반복, 충남 단어는 첫 줄 또는 마지막 줄 강박(brief 12절).
- 훅은 랩이 아닌 **멜로디 있는 가창**(사람이 직접). 벌스 랩과 대비를 만든다.
- 훅 단독으로 뜻이 통하고 "충남" 자리를 시·군명으로 바꿔도 리듬이 유지되어야 한다(개사 슬롯).
- 후렴 문장은 유사성 리포트의 피할 표현(어서와유, 괜찮아유, 충남의 노래 문구 등)과 겹치지 않게 직접 창작한다.

### 2-3. 첫 8초·30초
| 시간 | 내용 |
|---|---|
| 0~8초 | 2마디 비트 인트로 + 훅 한 줄 선공개 태그("충남" 포함). 1초 안에 비트가 시작되어야 한다 |

## 3. 사업적합성 확보법
- 충남 요소 위치: (1) 훅 첫 줄 또는 마지막 줄(필수), (2) 벌스 1의 마지막 2줄에 소재 장면(신두리 등 구체 지명·풍경), (3) 벌스 2에 생활·음식·이동 중 하나(근거 확인된 것만), (4) 아웃트로 태그에 "충남" 재등장.
- 벌스 랩은 지명 나열 금지(클리셰). 한 장면을 구체적으로 그리고 지명은 2~3개 이내.
- 컷 아웃 설계:
  - 15초: 훅 4줄(약 8마디=20초 중 앞 6마디 또는 훅 4마디 재편곡 버전) + 끝 태그 "충남". 훅 단독 완결.
  - 30초: 벌스 마지막 4마디(장면 1줄) + 훅 전체 + 태그. 벌스 마지막 4마디가 독립적으로 들려야 한다.
  - 홍보영상: 인트로·간주 짧게, 훅 멜로디 인스트루멘털 버전을 별도 믹스(사람이 제작)하면 편집점이 늘어난다.
- 개사: 훅 "충남" 슬롯을 시·군명으로 대체 가능한 리듬으로 작성. 당선작은 편곡·개사되어 비영리 활용될 수 있음(`rules-checklist.md`).

## 6. Suno 데모 설정 (방향 탐색용, 제출 불가)
### Styles (영문, 약 640자, 1000자 이내)
```
Korean melodic hip-hop, modern boom-bap inspired drums with crisp snare and light hi-hats, warm electric piano chords, deep sub bass, short catchy synth lead, 96 BPM, half-time feel, confident but friendly Korean rap verses with clear pronunciation, sung melodic hook with stacked harmonies, bright uplifting mood, road trip and open sea breeze atmosphere, stylish and clean modern production, catchy singalong chorus, chorus arrives within the first 25 seconds, call and response breakdown before the final chorus, radio and short-form friendly, about 3 minutes
```
### Exclude styles
```
trot, screaming, heavy distortion, drill, aggressive trap, explicit lyrics, profanity, diss, English lyrics, sad ballad, K-pop idol dance, autotune-heavy, sample of existing songs
```
### 가사 입력
- 구조 태그만 넣거나, 사람이 쓴 짧은 초안을 넣는다. 가사 없는 비트 탐색은 Instrumental 켬으로 실행.
```
[Intro] [Hook] [Verse 1] [Hook] [Verse 2] [Hook] [Breakdown] [Verse 3] [Final Hook] [Outro]
```
### 옵션
| 항목 | 값 |
|---|---|
| Custom mode | 켬 |
| Instrumental | 비트 탐색용 생성은 켬, 훅 느낌 확인용은 끔 |
| Vocal gender | Male / Female 각각 |
| Weirdness / Style influence | 30~40% / 60~70% |
| Audio influence / Persona | 사용 안 함(타인 곡·목소리 영향 방지) |
| 길이 | 3분 내외 |

### 생성 전략
- 총 8~12개: 인스트루멘털 4개(BPM 92 / 96 / 100, 조성 변주), 보컬 포함 4~8개(남/여 각각).
- 비교 방법: (1) 첫 8초 각인, (2) 30초 안 훅 도달, (3) 훅 15초 컷이 단독으로 끊기는지, (4) 라이브에서 DJ+MC로 재현 가능한지, 각 항목 사람이 청취 후 5점 척도로 기록. 점수는 내부 참고이며 수상 가능성이 아니다.
- 결과 활용: 템포·드럼 질감·코드 분위기·구성 흐름의 참고. 음원·가사·멜로디를 제출물에 복사하지 않는다. 사용 도구·범위를 `ai-usage-log.md`에 기록.
- 특정 아티스트·곡을 지시하는 문구는 프롬프트에 쓰지 않는다(장르 용어만 사용).
