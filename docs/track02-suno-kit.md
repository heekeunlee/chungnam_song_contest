# Track 02 Suno 데모 키트 v6 - 열다섯 얼굴 (영상화 최적안, 트렌디 랩팝)

용도: 방향 탐색 데모. **제출 음원·제출 가사로 그대로 쓰지 않는다.** 제출곡은 랩 가사·훅 멜로디·비트·녹음을 사람이 직접 한다. 사용 내역은 `docs/ai-usage-log.md`와 신청서에 사실대로 기재한다.
개정(v6, 2026-09-29): 영상화(홍보영상·CM·뮤직비디오) 적합성 기준으로 후렴 확정. 훅 '열다섯 시군 열다섯 얼굴', 벌스·브리지에서 '느림' 표현 제거, 벌스는 컷 단위 장면 구조. 가제 '열다섯 얼굴'(기존 '쌓는 중'은 벌스 모티프로만 사용).
사실 범위: 공고문의 충남 15개 시·군, 신두리 사구 천연기념물·바람이 쌓은 모래언덕, 논산 딸기 축제, 공주 공산성, 부여 정림사지. '~유'·"어서와유"·"노잼"·충남 공식 슬로건 미사용.
유사성 1차: 웹 검색에서 "열다섯 얼굴"·"하나로 부르면 충남" 정확 일치 사례 미발견(스니펫 기준, 표절 아님을 뜻하지 않음). 유튜브·음원 사이트 내부는 미조사.

## 영상화 최적 선정 이유
1. 후렴이 '숫자 카운트' 구조라 화면에 1→15 카운터와 15개 컷을 맞추기 쉽다(컷 편집 리듬 = 후렴 리듬).
2. 4줄이 각각 독립 컷이라 15초 CM에 후렴 1회로 완결된다. "충남!" 응답이 로고·자막 타이밍이 된다.
3. 시·군 개사: "열다섯 시군"→"OO시", 얼굴 컷을 지역 홍보영상별로 교체 가능(사업적합성, 활용성).
4. 자랑·비교·느림·부정 낙인이 없어 지자체 영상에 안전하다.

## 영상 컷 설계 (참고)
| 구간 | 화면 | 비고 |
|---|---|---|
| Intro | 어두운 화면에 카운터 "15" 점등, 첫 컷 | 0:00~0:05 |
| Verse 1 | 새벽 서쪽(신두리 사구, 바람 결, 발자국) → 내륙 이동(운전 시점) | 장면 = 가사 1줄당 1~2컷 |
| Pre-Hook | 손가락으로 세는 카운트(하나 둘, 셋 넷) | 화면 분할 준비 |
| Hook | 카운터 1→15 상승, 시·군별 얼굴 컷 빠른 전환, "충남!"에 로고·자막 | **15초 CM = 후렴 1회** |
| Verse 2 | 딸기 축제 가판대, 공산성 성곽, 정림사지 석탑 앞 뜰 | 촬영·이미지 사용권 확인 |
| Bridge | 음악 멈추고 박수만, 방문객 시선 컷 | 시청자에게 말 걸기 |
| Final Hook | 15개 컷 그리드 완성 후 하나의 도 지도로 합쳐짐 | 엔딩 로고 |
- 30초 컷: Verse 2 마지막 4줄(열다섯 중에 몇 곳…) + 후렴 1회.
- 15초 컷: 후렴 4줄. 인트로 1줄 생략 가능.
- 촬영·이미지·로고는 저작권·초상권·사용 허가를 확인한다(제출 심사는 음원 기준, 영상은 당선 후 활용).

## 표절 시비 최소화 원칙 (완전한 배제는 불가)
1. 프롬프트에 아티스트·곡명·"~풍" 지시를 쓰지 않는다.
2. **훅 멜로디는 사람이 직접 작곡한다.** 숫자를 세는 리듬은 흔하므로 음정 진행을 독자적으로 만든다.
3. 코드 진행은 사람이 정하고 아주 흔한 진행 하나만 반복하지 않는다.
4. 훅을 허밍 녹음해 음악 인식 앱과 유튜브로 확인하고 결과를 기록한다.
5. "열다섯 얼굴", "하나로 부르면 충남", "다 다르니까 충남", "한 곳씩 한 얼굴씩"을 멜론·지니·유튜브에서 직접 검색한다.
6. 충남 공식 슬로건("통하는 충남", "힘쎈충남" 등, 검색 스니펫 기준)과 겹치지 않는다.
7. 제작 과정을 `ai-usage-log.md`에 남긴다.

## 확인·주의
- "논산 딸기 축제 가판대", "공산성 성곽", "정림사지 석탑 앞 뜰"은 장면 묘사다. 공식 자료로 재확인한다.
- "지나가는 길이라던 그 말은 접고"는 통념 반전이다. 충남 분들이 불편해할 수 있으면 삭제해도 후렴·구조에 영향 없다.
