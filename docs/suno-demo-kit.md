# Suno 데모 키트 01 - 길이 열리는 시간 (간월암 물때, 포크팝)

용도: 방향 탐색·레퍼런스 데모. **제출 음원·제출 가사로 그대로 쓰지 않는다.**
제출곡은 응모자가 가사를 고쳐 쓰고 멜로디를 새로 만들고 직접 녹음한다. 사용 내역은 `docs/ai-usage-log.md`와 신청서에 사실대로 기재한다.
방향: 유사성 조사(`docs/similarity-report-1.md`) 반영. '~유'는 사용하지 않고 간월암 물때 장면 중심. 피할 표현: "어서와유", "황금해 뜨는 서산", 간월암 공식 문구.
