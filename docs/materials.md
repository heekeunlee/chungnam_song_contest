# 소재 카드 5개 (소재 리서처, 2026-09-29)

범위: 가사·곡 없음. 출처는 실제로 열어본 URL만 기재. 확인 못한 것은 '미확인'.
주의: 장면 이미지·고유 단어 후보는 조사 내용에서 뽑은 제안이며, 최종 선택과 창작은 사람이 한다.

## 1. 간월암 물때 (서산) - 열렸다 닫히는 길
- 대표 지명: 서산시 부석면 간월도리 (간월암, 간월도)
- 한 줄 요약: 밀물엔 바다 위 섬, 썰물엔 걸어가는 길이 되는 암자. 시간을 맞춰야 닿는 곳.
- 장면 이미지: (1) 만조에 바다 한가운데 떠 있는 암자와 낙조 (2) 물이 빠져 바닷길로 걸어 들어가는 사람들
- 고유 단어: 간월암, 간월도, 물때, 밀물·썰물, 굴(어리굴젓)
- 식상함 위험: 낮음~중간. 태안·보령 '노을'보다 '물때' 각도가 독특. 기존 노래 사례는 미확인(조사 안 함).
- CM송·영상 활용성: 높음. 시각 변화가 뚜렷해 영상 전개(열림/닫힘)에 유리. 단 서산 한정 소재라 '충남 전체' 공감은 약함.
- 확인된 사실: 무학대사 관련 유래, 만공선사 중창, 앞마당 약 200년 된 사철나무, 정월대보름 만조 때 굴부르기군왕제(어리굴젓 축제).
- 출처: https://www.ohmynews.com/NWS_Web/View/at_pg.aspx?CNTN_CD=A0003100088 / https://www.koya-culture.com/news/article.html?no=151943 / https://www.seosan.go.kr/tour/guideView.do?key=5983&guidanceNo=936&lclas=CRLTS&sclas=TDTBDHTML&langSe=KOR
- 주의: 서산시 페이지 요약에는 밀물/썰물 서술이 반대로 나옴(요약 오류 가능). 오마이뉴스·우리문화신문 서술(만조=섬)을 채택.

## 2. 신두리 해안사구 (태안) - 바람이 쌓은 모래언덕
- 대표 지명: 태안군 원북면 신두리
- 한 줄 요약: 약 1만 5천 년 바람이 쌓은 국내 최대 해안사구. 바다·모래·풀이 만드는 풍경.
- 장면 이미지: (1) 바람에 결이 진 모래언덕 위 발자국 (2) 사구 너머 갯벌과 바다
- 고유 단어: 신두리, 사구, 모래, 바람, 해당화(식물 종 미확인 - 원문은 통보리사초·갯메꽃 등 언급, 개별 종 확인 필요), 태안
- 식상함 위험: 낮음(노래 소재로는 드묾, 기존 곡 조사는 미확인). 다만 '태안 바다=노을' 클리셰와 겹치지 않게 주의.
- CM송·영상 활용성: 중간~높음. 드론·와이드 영상에 좋음. 서정적이라 리듬감 있는 CM송에는 각색 필요.
- 확인된 사실: 천연기념물 제431호(2001.11.30), 면적 170.2ha, 길이 3.4km·폭 1.3km, 약 1만 5천 년 형성, 쇠똥구리 복원 언급, 탐방로 A/B/C 코스, 슬로시티 언급.
- 출처: https://www.chungnam.go.kr/cnportal/media/article/view.do?articleNo=MD0003158845&menuNo=500167 / https://korean.visitkorea.or.kr/detail/ms_detail.do?cotid=ef6b2358-4d94-417b-85bf-8cc9b5c803dc
- 주의: 두 페이지 모두 '해당화'는 확인 못함. 종 이름은 사용 전 재확인.

## 3. 논산 딸기 - 봄을 먼저 파는 붉은 동네
- 대표 지명: 논산시 (논산시민가족공원 축제장)
- 한 줄 요약: 전국 대표 딸기 주산지. 3월 말 딸기축제에 2026년 67만여 명이 찾음.
- 장면 이미지: (1) 하우스 안에서 딸기를 따는 손 (2) 축제장 벚꽃철 붉은 딸기 가판대와 사람들
- 고유 단어: 논산, 딸기, 하우스, 달콤, 설향(품종명은 이번 조사에서 미확인)
- 식상함 위험: 중간~높음. 딸기 자체가 '달콤·사랑' 클리셰로 흐르기 쉬움. 딸기 노래가 많을 것으로 예상되나 조사 안 함(미확인).
- CM송·영상 활용성: 높음. 색·소리가 밝아 CM송에 적합. 단 논산 한정 소재라 '충남 전체' 공감은 약함.
- 확인된 사실: 1997.4.11 '딸기 벚꽃 축제'로 시작, 2008년 재배면적 955(원문 단위 오기 ㎏, 검색 결과는 ha) 전국의 13%·충남의 45%, 연 생산 약 3만 톤·수입 약 1천억 원, 충남관광 페이지는 전국 생산량 약 15%로 기재(수치 불일치, 인용 시 연도 명시). 2026.3.26~29 축제 방문 67만여 명·딸기 150t 판매(검색 결과, 원문 페이지 미열람).
- 출처: https://tour.chungnam.go.kr/prog/fstvl/kor/sub02_02_02/view.do?fstvlNo=77 / https://www.grandculture.net/nonsan/toc/GC02000446

## 4. 웅진·사비 백제 (공주·부여) - 옛 도읍의 시간
- 대표 지명: 공주(공산성, 무령왕릉), 부여(부소산성, 정림사지, 나성)
- 한 줄 요약: 475~660년 백제 후기 도읍의 유적. 유네스코 세계유산.
- 장면 이미지: (1) 성곽 위에서 강과 도시를 내려다보는 저녁 (2) 정림사지 오층석탑 앞 고요한 뜰
- 고유 단어: 백제, 공주, 부여, 웅진, 사비 (금강은 이번 조사 원문에서 미확인)
- 식상함 위험: 높음. 백제=역사 교과서 이미지, 지자체 홍보 노래에 흔할 가능성(미확인). 관점을 바꾸지 않으면 관광지 나열로 흐름.
- CM송·영상 활용성: 중간. 콘텐츠는 풍부하나 젊고 가벼운 CM송 톤과 거리. 2개 시·군에 걸침.
- 확인된 사실: 유적 8곳(공주 2, 부여 5, 익산 2 중 충남은 공주·부여). 유네스코 기준 (ii)(iii). 백제는 기원전 18년~660년, 후기 475~660. 2015년 등재(검색 결과, 원문 페이지 확인은 위키백과 요약 수준).
- 출처: https://www.gongju.go.kr/tour/sub01_01_01.do / https://www.heritage.go.kr/heri/html/HtmlPage.do?pg=%2Funesco%2FHeritage%2FHeritage_12.jsp&pageNo=5_1_2_0
- 주의: 위 두 페이지의 유적 수는 원문상 공주 2·부여 5·익산 2로 합계 9처럼 보이나 공식 표기는 8곳(부여 4곳으로 정리하는 자료 있음). 사용 전 재확인.

## 5. 충남 말투 '~유' (충남 전체) - 느릿하고 여유로운 말
- 대표 지명: 충남 전역(천안·아산·예산 등 어르신 사용 언급은 검색 결과 기준)
- 한 줄 요약: '~유', '~여' 어미로 느리고 순한 충청 말투를 충남 정체성으로 삼기.
- 장면 이미지: (1) 장터·마을 정자에서 서로 안부 묻는 어르신 (2) 길 묻는 여행객에게 느긋이 알려주는 동네 사람
- 고유 단어: ~유, ~여, 뭐여, 괜찮어, 알았유 (발음 쉽고 후렴에 얹기 쉬운 후보)
- 식상함 위험: 낮음~중간. '충청도 느림' 개그 소재로는 흔하나, 공모곡·CM송 사례는 미확인. 유머/조롱 톤은 피할 것.
- CM송·영상 활용성: 높음. 15개 시·군 모두 공감 가능, 개사·재편곡·짧은 훅 활용에 유리. 지명 없이도 '충남'이 각인됨.
- 확인된 사실: 충청 방언은 '~유'를 요 대신 씀, '~슈'는 현대에 거의 안 씀, '~여'·'겨?' 사용, 말투가 느리고 온화하다는 이미지(위키백과·나무위키). 젊은 세대는 사용이 감소(나무위키).
- 출처: https://ko.wikipedia.org/wiki/%EC%B6%A9%EC%B2%AD_%EB%B0%A9%EC%96%B8 / https://namu.wiki/w/%EC%B6%A9%EC%B2%AD%20%EB%B0%A9%EC%96%B8
- 주의: 출처가 위키류라 근거 강도는 약함. 충남 15개 시·군 전역 사용 여부는 미확인(충북·대전·경기 일부와 공유되는 방언). 충남만의 소재라는 점은 약해 '충남 전체' 로 쓸 때 지명·풍경과 조합 필요.

## 추천 순위 (5줄)
1. 충남 말투 '~유': 15개 시·군 공감, 후렴 훅과 CM송 활용성 최고. 단 충청 공유 방언이라 충남 지명 한두 개와 결합 필요.
2. 간월암 물때: 열림/닫힘이라는 뚜렷한 장면과 은유(기다림·타이밍), 식상함 낮음.
3. 신두리 사구: 참신하고 영상성 좋으나 서정 쏠림. 리듬 곡에는 각색 필요.
4. 논산 딸기: CM송 친화적이나 딸기=달콤 클리셰 위험, 한 지역 한정.
5. 백제 공주·부여: 충남다움은 최강이지만 가장 흔한 접근. 다른 소재와 결합할 때만 권장.

## 미확인 사항
- 각 소재의 기존 노래 사례(지자체 홍보곡·대중가요) 조사 안 함. 독창성 리서처에 넘길 것.
- 2026 딸기축제 67만 명 수치는 검색 결과 스니펫만 확인, 원문 페이지 미열람.
